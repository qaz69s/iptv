# P7 阶段报告：设置、家长控制、备份恢复、定时更新、多语言

> **未经编译验证**：代码没有构建或运行过。

## 做了什么
- **设置页**（底部导航新增“设置”）：
  - 外观：主题（跟随系统 / 浅色 / 深色 / AMOLED 纯黑）、5 种主色、字体大小（80%~140%）、语言（跟随系统 / 简体中文 / English，切换后立即重建界面）。
  - 播放：解码模式（硬解优先 / 仅软件解码）、缓冲档位、默认画面比例、启动时自动续播、后台播放、自动播放下一集（默认关闭）、最大重连次数（0~20）、是否允许计费网络。
  - 节目单：更新频率（6 / 12 / 24 / 48 小时）、保留天数（1~7 天）、时间偏移（±12 小时，步长 0.5 小时）、立即更新全部节目单。
  - 播放列表：进入管理页。编辑对话框里新增更新策略（手动 / 每次启动 / 每 N 小时）、“允许明文 HTTP”开关和 Xtream 修改密码。
  - 家长控制：设置 / 修改 / 移除 PIN（4~6 位，输两次确认），锁定设置页，锁定播放列表编辑器；单个频道或分组在编辑器里锁定。
  - 备份与数据：导出 / 恢复 JSON 备份，清空观看历史。
  - 关于：免责声明、隐私政策、版本号。
- **PIN 生效范围**：点击锁定的频道或分组、从提醒或通知直达、启动自动续播（锁定的频道会被跳过）、上下切台和数字直输（自动跳过锁定频道，输对 PIN 后 5 分钟内不跳过）、播放列表编辑器、设置页。连续输错会锁定一段时间，锁定时长逐次翻倍。
- **明文 HTTP**：新建播放列表默认**只允许 HTTPS**；添加时或编辑时可以为单个列表打开“允许明文 HTTP”。被拦截时，导入和播放都会提示“此播放列表不允许明文 HTTP”。
- **定时更新**：`PlaylistUpdateWorker`，失败时指数退避重试；更新后收藏、隐藏、排序、重命名都会保留（P3 的覆盖机制）。
- **备份**：不包含任何密码明文；恢复时追加为新列表，并提示哪些 Xtream 列表需要重新输入密码。
- **多语言**：所有界面文字都在各模块的 `strings.xml`（英文默认 + `values-zh-rCN`）；开启了 `generateLocaleConfig`。
- **测试**：`PinTest` 7 个（格式校验、计数、锁定与到期、锁定时长翻倍与上限、哈希校验与盐值、未知哈希格式）。

## 没做 / 限制
- 字体大小只影响 Compose 界面，不影响字幕（字幕有单独的样式设置）。
- 备份恢复不会自动开始导入频道，需要手动刷新（或等待已设置的更新策略执行）。

## 已知问题 / 行为变化
- `allowCleartext` 的默认值从 true 改成了 false。在旧测试包里建的 http 列表需要在编辑里打开开关（或者清除应用数据后重新添加）。
- 切换语言时会重建 Activity，正在播放的视频会短暂黑屏（声音不会中断，播放器是单例）。
