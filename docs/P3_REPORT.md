# P3 阶段报告：搜索、收藏、历史、分组管理、列表编辑器

> **未经编译验证**：代码没有构建或运行过。

## 做了什么
- **频道浏览（§4.2）**：分组里新增“全部 / 收藏 / 最近观看”三个虚拟分组。视图有列表、网格、紧凑三种，排序有默认、名称、频道号、自定义四种，都写入设置。手机用分组 Chip；TV 和平板（最短边 ≥ 600dp）用左侧分组、右侧频道两栏。加载中、空列表、出错（带重试）三种状态都有。
- **搜索**：点放大镜展开搜索框，输入停顿 300ms 后自动搜索。FTS4 同时搜频道名和分组名（`channel_fts` 新增 `groupName` 列）；当前节目名的搜索在 P4 加入。
- **收藏**：列表每行和播放页顶部都有星标。收藏用 `playlistId + uniqueKey` 标识，刷新列表后不会丢。底部导航新增“收藏”页，汇总所有播放列表的收藏。
- **观看历史**：每次播放写一条记录，只保留最近 50 条，“最近观看”分组直接读这张表（清空入口在 P7 的设置页）。
- **播放列表管理**：启用/停用（停用的列表不出现在频道页）、上移/下移、立即更新（带进度和失败原因）、编辑（名称、地址、UA、EPG 地址）、删除前二次确认（会同时删掉收藏、历史和编辑记录）。
- **列表编辑器**：分组可以隐藏/显示、重命名、上下移动、锁定、新建自定义分组；频道可以隐藏、重命名、上下移动、锁定、移动到其他分组。所有编辑在列表刷新后都会自动重新套用。
- **导航**：手机用底部导航（频道 / 收藏），TV 和平板用侧边导航栏；后面的阶段会继续加“节目单”“点播”“设置”。
- **播放页**：进入时隐藏系统栏（沉浸式全屏），退出时恢复。
- **测试**：新增 `FtsQueryTest`（3 个）。

## 没做 / 限制
- 锁定标记已经能保存，但**输入 PIN 才能播放**要到 P7（家长控制）才生效。
- 编辑器只能用“上移/下移”按钮调整顺序，不支持拖拽（这样 TV 遥控器也能操作）。
- 频道清掉自定义名称后，要等下次刷新列表才恢复原名（分组会立即恢复）。
- 同一个 tvg-id 对应多个频道时（比如 HD 和 SD 版本），它们共用一个收藏和编辑标识，这是按说明书 §4.7 的唯一键规则来的。
