# P2 阶段报告：播放器完善

> **未经编译验证**：本阶段代码没有在 Android SDK / Gradle 环境中构建或运行过，单元测试也未实际执行。

## 做了什么
1. **模块拆分（§6）**：页面代码从 `app` 拆到 `feature:playlist`（首启 + 添加列表）、`feature:channels`（频道列表/搜索）、`feature:player-ui`（播放）；新增 `core:common`、`core:network`、`core:datastore`、`core:data`、`core:designsystem`。`PlayerController` 留在 `core:player`。feature 之间无依赖，导航只在 `app`。
2. **轨道选择**：清晰度（含自动）、音轨、字幕（内嵌 + SAF 选择外挂 SRT/VTT/SSA/TTML，按扩展名判断 MIME）；字幕样式：大小 5 档、颜色 4 种、背景 3 种，持久化到设置。
3. **画面比例**：自适应 / 16:9 / 4:3 / 填充（裁剪）/ 拉伸 / 原始尺寸（按视频像素 1:1，超出部分裁剪）。
4. **手机手势**：左右滑动调进度（仅点播）、左半屏上下滑亮度、右半屏上下滑音量、双击左/右 ∓10 秒（仅点播）、双击中间暂停、单击显示/隐藏覆盖层。
5. **遥控器**：上/下切台（ChannelUp/Down 同样生效）、左/右：直播调音量 / 点播快退快进、OK 显示或隐藏信息条、MENU/设置/INFO 键打开轨道/比例面板、数字键直输（2 秒无输入自动确认，OK 立即确认）、播放/暂停媒体键。
6. **覆盖层**：频道号 + 名称、Logo、时钟（跟随系统 12/24 小时制）、睡眠剩余时间；4 秒自动隐藏；点播显示进度条和播放/暂停。P4 会在同一位置加当前/下一节目（`OverlayProgram` 参数已预留）。
7. **缓冲三档**：低延迟 / 均衡 / 稳定（`DefaultLoadControl` 参数见 `PlayerController.kt`）。
8. **重连**：`ReconnectPolicy` + `ReconnectSession`（指数退避、±20% 抖动、上限 30 秒、最大次数取自设置），网络恢复时立即重试；UI 显示“正在重连 (n/max)”；失败后给出明确原因：HTTP 状态码、超时、网络、解码、明文 HTTP 被拦截、计费网络被禁止。
9. **PiP / 后台播放**：手机/平板按 Home 键且正在播放时进入画中画（API 26+，TV 不进入）；`PlaybackService` 提供媒体通知和耳机/蓝牙控制；“后台播放”设置项关闭时退到后台会暂停；关闭 PiP 窗口时暂停。屏幕常亮只在播放中持有。
10. **睡眠定时**：15/30/60/90 分钟 + 自定义分钟；到点 5 秒淡出后暂停并恢复音量。
11. **记住上次频道**：每次播放写入 `playlistId + uniqueKey`；设置“自动继续播放”打开时，启动后直接进入该频道（设置开关的界面在 P7）。
12. **UDP 组播**：`udp://` 流自动申请 `MulticastLock`。
13. **测试**：M3U 解析单测 10 → 36 个；`ReconnectPolicyTest` 9 个；`RedactTest` 4 个；`BufferProfileTest` 2 个。修正了解析器的一个问题：标题现在取第一个引号外逗号之后的全部文本，所以 `News, Live` 这类标题不会被截断。

## 新增权限及用途
- `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK`：后台音频播放服务。
- `POST_NOTIFICATIONS`：Android 13+ 显示媒体通知（首次进入播放页时申请，拒绝也不影响播放）。
- `WAKE_LOCK`：播放时保持网络唤醒。
- `CHANGE_WIFI_MULTICAST_STATE`：接收 `udp://` 组播流。

## 没做 / 限制
- `rtp://` 地址会交给 UDP 数据源，带 RTP 头的流可能无法解析；Media3 没有原生 RTP-over-UDP 支持，需要自定义 DataSource（后续可做）。
- RTMP：你选择不启用，所以没有引入 RTMP 扩展。
- 相邻频道预加载（§5 可选）未做。
- “自动播放下一集”属于点播，放在 P6。
- 亮度只调当前窗口，不改系统亮度（这样不需要 WRITE_SETTINGS 权限）。
