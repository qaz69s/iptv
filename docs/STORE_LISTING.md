# 应用商店文案草稿

## 名称
StreamDeck Player — IPTV 播放器 / IPTV Player

## 简短说明（≤ 80 字符）
- 中文：播放你自己的 IPTV 列表：M3U、Xtream、EPG 节目单、回看，支持手机与电视。
- EN: Play your own IPTV playlists — M3U, Xtream, EPG guide & catch-up on phone and TV.

## 详细说明（中文）
StreamDeck Player 是一款简洁高效的 IPTV 播放器，手机、平板、Android TV 都能用。

**重要声明：本应用仅为播放器，不提供内容，用户需自行承担所添加内容的合法性。**

- 多个播放列表：M3U / M3U8 网址、本地文件、Xtream Codes
- 网格节目单（XMLTV，支持 .gz），频道自动匹配，节目提醒
- 回看和时移（default / append / shift / flussonic / xc 等类型）
- 电影和剧集：续播、已看标记、自动下一集
- 硬件解码优先，可切换为仅软件解码；字幕、音轨、清晰度和画面比例都能调
- 手势调节亮度、音量、进度；电视遥控器数字键直接换台
- 收藏、观看历史、列表编辑器（隐藏、重命名、排序、自定义分组）
- 家长控制 PIN、备份与恢复、Chromecast 投屏、画中画、后台播放
- 深色 / AMOLED 主题，中文和英文界面

## Full description (English)
StreamDeck Player is a fast, clean IPTV player for phones, tablets and Android TV.

**This app is only a player and provides no content. You are solely responsible for the legality of any content you add.**

Multiple playlists (M3U URL / file / Xtream Codes) · grid TV guide (XMLTV) with reminders · catch-up & time-shift · movies & series with resume · hardware decoding with software fallback · subtitles, audio tracks, quality, aspect ratio · gestures and remote-control number zapping · favorites, history and playlist editor · parental PIN · backup/restore · Chromecast · picture-in-picture · background audio · dark/AMOLED themes.

## 分类 / 标签
视频播放器和编辑器 · IPTV · M3U · EPG · Android TV
