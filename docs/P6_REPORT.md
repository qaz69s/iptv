# P6 阶段报告：Xtream Codes（直播 + 点播）

> **未经编译验证**：代码没有构建或运行过。

## 做了什么
- **添加 Xtream 账号**：填写服务器地址、用户名、密码；导入前先登录校验，账号状态不是 Active（例如已过期）时会给出明确原因。密码用 Android Keystore 加密后保存。
- **直播**：先拉分类（变成分组），再逐条读取直播流（变成频道），每 1000 条存一批，原子替换。频道号、Logo、EPG id、回看信息（tv_archive / tv_archive_duration）都会带上。直播频道和 M3U 频道共用收藏、编辑器、搜索、EPG 和回看逻辑。
- **EPG**：自动使用 Xtream 自带的 `xmltv.php`，下载时才拼上凭据。
- **回看**：使用 `xc` 类型，并使用面板返回的服务器时区。
- **点播**（新增 `feature:vod`，底部导航新增“点播”）：
  - 电影和剧集两个页签，可按分类筛选、按名称搜索（300ms 防抖），海报网格分页加载。
  - 电影详情：海报、评分、时长、类型、上映日期、简介，以及“播放 / 继续播放”“标记已看 / 未看”。
  - 剧集详情：按季切换，分集列表显示时长和进度条，可标记已看。
  - 续播：每 10 秒保存一次进度，退出播放页时也会保存；看到 95% 自动算作已看。
  - 自动播放下一集：读取设置项“自动播放下一集”（**默认关闭**，开关界面在 P7），打开后一集播完自动接下一集。
- **测试**：`XtreamParsersTest` 10 个，`VodKeyTest` 3 个。

## 没做 / 限制
- 直播流统一用 `.ts` 格式，没有提供“改用 m3u8”的选项。
- 点播目录的更新跟着播放列表刷新一起进行；如果点播部分失败，会保留旧目录，但**不会提示**（直播部分的导入结果不受影响）。
- 点播内容不进入收藏或观看历史（历史只记录直播频道）。

## 已知问题
- 个别面板的 `get_series_info` 返回格式和常见格式差别很大，可能取不到分集；解析器已经兼容常见的几种变体。

## 手动验收清单（P6）
- [ ] 填入有效 Xtream 账号后能导入直播分组和频道；填错账号时提示“服务器拒绝登录”
- [ ] 直播可以播放，EPG 自动加载，支持回看的频道可以回看
- [ ] 电影和剧集能浏览、搜索、播放；中途退出后重新进入能从断点继续
- [ ] 打开自动播放下一集后，剧集能连续播放
