# P4 阶段报告：EPG（XMLTV）、匹配、网格视图、提醒

> **未经编译验证**：代码没有构建或运行过。

## 做了什么
- **XMLTV 解析器**（`core:parser`，纯 Kotlin）：流式解析，支持多个 display-name、icon、多语言 title（取第一个）、desc 里嵌套标签和 CDATA；缺少 stop 时默认 1 小时；只保留指定时间窗内的节目。时间格式支持 `YYYYMMDDhhmmss ±hhmm`，也支持 `±hh:mm`、省略秒/分钟、省略时区（按 UTC 处理）。
- **来源**：xml / xml.gz（自动识别 gzip）/ http(s) / content://（本地文件）。M3U 文件头里的 `url-tvg` / `x-tvg-url` 会自动填进播放列表的 EPG 地址，也可以在“管理播放列表”里手动填写。Xtream 自带的 EPG 在 P6 接入。
- **入库**：每 1000 条一个事务，用 pending 行原子替换；保留天数取自设置（默认 3 天），始终额外保留前 1 天。
- **频道匹配**：tvg-id → tvg-name → 规范化名称 → 编辑距离 1 的模糊匹配；在频道节目页可以“指定 EPG 频道”手动匹配，手动结果不会被覆盖。每次刷新播放列表或 EPG 后都会自动重新匹配。
- **视图**：
  - 网格 EPG：横向是时间（前 2 小时到后 24 小时，每格 30 分钟），纵向是频道，可按分组筛选；有当前时间线，正在播出的节目高亮；所有节目格都能获得焦点（TV 遥控器可用）。
  - 频道节目页：今天 / 明天 / 一周。
  - 频道列表每一行显示当前节目名（直接在 SQL 里计算）；搜索也能搜到当前节目名（新增节目 FTS 表）。
  - 播放页信息条显示当前节目时间、进度条和下一节目。
- **节目详情**：标题、频道、日期和起止时间、分类、海报、简介；根据节目状态显示“观看直播”“回看”或“提醒我 / 取消提醒”。
- **提醒**：WorkManager 一次性任务，到点发本地通知，点通知直接打开该频道；勾选“自动切台”且应用在前台时直接切台。
- **定时更新**：`EpgUpdateWorker` 按设置的间隔运行（默认 24 小时）；网络异常时指数退避重试，最多 3 次；顺带清理过期节目和提醒。“禁止计费网络”打开时只在不计费网络（如 Wi-Fi）下更新。
- **EPG 时间偏移**：`EpgClock` 统一处理真实时间、EPG 源时间和显示时间，偏移在查询和显示时应用（设置界面在 P7）。
- **明文 HTTP 拦截**：`CleartextGuardInterceptor` 已接入。目前所有播放列表默认允许明文 HTTP，所以行为没有变化；每个列表单独开关的界面在 P7。
- **测试**：`XmltvParserTest` 6 个，`XmltvTimeTest` 8 个，`EpgMatcherTest` 8 个。

## 没做 / 限制
- **回看按钮**：P4 里点“回看”会先播直播；真正的回看在 P5 接上。
- **提醒时间**：提醒可能比开播晚几分钟（WorkManager 不保证准时）。如果要求精确，需要 `SCHEDULE_EXACT_ALARM` 权限，这超出了说明书列的必要权限，所以没有申请。
- **网格范围**：网格只显示当前播放列表、选中分组的频道。选“全部”且频道上万时首屏会慢一些，因为每一行在出现时才查自己的节目。

## 已知问题
- 数据库仍是 v1，新增了 5 张表；装过旧测试包需要先清除应用数据。
- 匹配率受 EPG 来源质量影响很大，模糊匹配刻意设得保守（只允许 1 个字符的差异）。
