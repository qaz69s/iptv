## 用户决定（2026-11-18 确认）
1. 编辑器入口：播放列表管理里按播放列表进入；频道长按菜单提供快速「隐藏 / 重命名」。
2. 隐藏项在编辑器里灰显并带开关；区分「自身隐藏」与「随分组隐藏」。
3. 编辑器内重排频道后，浏览排序自动切到「自定义」。
4. 自定义分组（Room v3）：一个频道可属于多个分组，可跨播放列表；作为虚拟分组显示，参与切台与台号（组内序号，规则同收藏）。
5. 停用播放列表只隐藏、保留数据；播放列表用上移 / 下移排序。
6. 分组改成已存在的名字时，显示上合并。
7. PIN 锁不在 P3c，推迟到 P7。

## 做了什么

### 数据层（Part 1）
- Room **v3**：新表 `custom_groups`、`custom_group_channels`（groupId + playlistId + uniqueKey 主键，随分组 / 播放列表级联删除）；`Migration2To3` 及迁移测试。成员按稳定键解析到当前代，刷新后保留；隐藏频道、停用列表的频道不列出，但保留成员资格。
- 编辑器查询：`observeEditorGroups` / `observeEditorChannels`，列出隐藏项，`selfHidden` 区分自身隐藏与随分组隐藏。
- `PlaylistDao.setEnabled` / `setSortOrder`；`CustomGroupsRepository`（名字去空格，拒绝空名，同名复用）；`ChannelSource.Custom(groupId)` 接入切台、自动下一个、台号。

### 界面（Part 2）
- **播放列表管理**：每个列表的「显示此播放列表的频道」开关（停用 = 隐藏，数据保留）、上移 / 下移、「编辑列表」入口；顶栏「我的分组」入口。
- **列表编辑器第 1 级（分组）**：显示 / 隐藏、重命名（留空恢复原名；改成已有名字会合并显示）、上移 / 下移；灰显隐藏项，显示原名与频道数；点分组进入第 2 级。
- **列表编辑器第 2 级（频道）**：频道显示 / 隐藏、重命名、上移 / 下移（移动后浏览排序切到「自定义」）；「随分组隐藏」的频道单独标注，顶部提供「显示此分组」。
- **我的分组**：新建、重命名、删除（只删分组，频道保留）、上移 / 下移；进入分组可移除频道、调整组内顺序。
- **频道长按菜单**（触屏长按 / 遥控器长按 OK 或菜单键）：收藏、**隐藏**、**重命名**、**加入分组**（多选对话框，可直接新建分组）。
- 自定义分组在频道页作为虚拟分组显示在「最近观看」之后（手机 chips / TV 左栏），从中进入播放时按组内顺序切台，台号为组内序号。
- 所有可点元素有焦点环与 contentDescription；新增文案中英各一份。

## 已知问题
1. 频道很多的分组里，上移 / 下移一次只移一位，把频道移到很远需要多次操作。
2. 分组重排序保存的是当前列出的全部分组顺序；刷新后新出现的分组排在末尾。
3. 自定义分组里的频道若被隐藏或其列表被停用，不显示，但仍是成员；恢复后回到原位置。
4. 停用播放列表后，它的频道从「全部」、搜索、收藏、最近观看中消失，重新启用后恢复。
5. 全部界面改动未经真机验证；TV 上编辑器每行多个按钮的焦点顺序需要确认。
