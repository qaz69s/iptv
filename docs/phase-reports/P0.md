# P0 阶段报告：工程脚手架

日期：2026-11-15　应用：StreamBox Player（`com.streambox.player`）

## 做了什么
- 多模块 Clean Architecture 工程：`app`、`core:{common,model,domain,data,datastore,designsystem,ui,testing}`、`feature:{onboarding,channels,epg,settings}`；`build-logic` 约定插件统一 SDK、Compose、Hilt、测试、ktlint、detekt 配置，并禁止 feature 模块互相依赖（`checkNoFeatureDependencies`）。
- Version Catalog 集中管理依赖版本（见 `docs/implementation-plan.md`）。
- 首启流程：欢迎页 → 免责声明（必须勾选同意才能继续），状态存 DataStore。
- 主界面骨架：频道 / 收藏 / 节目单 / 设置四个入口，手机与平板用自适应 NavigationSuite，TV 用侧边 NavigationDrawer + 焦点高亮；TV 判断依据 leanback / UI mode，而非屏幕尺寸。
- 设计系统：浅色 / 深色 / AMOLED 纯黑主题、Android 12+ 动态取色开关、空/加载/错误状态组件、自绘矢量图标。
- 设置页：主题、动态取色、版本号、查看免责声明。
- 日志脱敏工具 `UrlRedactor`（账号、密码、token、Xtream 路径中的凭据一律打码）。
- TV Leanback 入口（LEANBACK_LAUNCHER + banner），触屏与 leanback 均声明为非必需，同一 APK 覆盖手机/平板/TV。
- 广告/内购：仅接口与空实现（按约定）；FFmpeg：未接入（按约定）。
- 中英文字符串、自适应图标、商店图标 512px、可选 release 签名（`keystore.properties`，模板已提供，不入库）。
- GitHub Actions CI（`.github/workflows/ci.yml`）：ktlint → detekt → 单元测试 → assembleDebug，上传 APK。
- 文档：README、ARCHITECTURE、本报告。

## 验证结果（沙箱）
`./gradlew assembleDebug test ktlintCheck detekt` → BUILD SUCCESSFUL
- 单元测试 22 项，0 失败（UrlRedactor 10、domain 3、datastore 1、onboarding 3、settings 3、app 2）
- ktlint、detekt 全部通过
- 产出 `app-debug.apk`（约 14.8 MB，未混淆的 debug 包）

## 没做什么（留到后续阶段）
- 播放列表导入/解析、频道列表、播放器、EPG 数据等实际功能（P1 起）。
- Compose UI 仪器测试与截图测试未在沙箱运行（需模拟器/真机）。

## 已知问题 / 偏差
1. Navigation Compose 降到 2.9.8、DataStore 降到 1.1.7：更新版本要求 minSdk 24，与说明书 minSdk 23 冲突。若接受 minSdk 24 可升回最新版。
2. 沙箱为 aarch64，aapt2 使用社区构建版；APK 能打出但未在真机/模拟器上运行验证，请在 Android Studio 或真机上安装确认（手机 + TV 各一次）。
3. detekt 对 `navigation/` 目录关闭了 MatchingDeclarationName（类型安全路由文件惯例写法）。
4. GitHub 仓库地址尚未提供，CI 尚未实际跑过。
